HTML

O que é HTML?

HTML (HyperText Markup Language ou Linguagem de Marcação de Hipertexto) é o código fundamental utilizado para estruturar e exibir o conteúdo de uma página na internet.

HTML é Linguagem de programação?

Não, o HTML não é uma linguagem de programação. Ele é uma linguagem de marcação.

Para o que serve o HTML?

Serve para criar a estrutura e organizar o conteúdo de uma página web.
